# ۱. معرفی پروژه — Internet Manager for MikroTik

## هدف
پنل وب سبک برای مدیریت پویای مسیر اینترنت کاربران روی روتر MikroTik.  
کاربران می‌توانند بین چند خروجی (ADSL، ایرانسل، همراه اول، VPN و ...) جابه‌جا شوند. ادمین همه کاربران را کنترل می‌کند و سوپرادمین ساختار سیستم (جدول‌ها و اینترفیس‌ها) را تعریف می‌کند.

## ویژگی‌های کلیدی
- سازگار با **RouterOS 6 و 7** (تشخیص خودکار نسخه)
- باینری استاتیک سبک (معمولاً ۸–۱۲ مگابایت)
- سه سطح دسترسی: کاربر / ادمین / سوپرادمین
- پشتیبانی از اینترفیس‌های عادی و VPN (WireGuard, OpenVPN, L2TP, SSTP, ...)
- ذخیره تنظیمات + بکاپ خودکار روی مسیر قابل mount
- ساختار ماژولار برای توسعه آسان

## نقش‌ها

| نقش | دسترسی |
|-----|--------|
| **کاربر** | فقط تغییر اینترنت خودش |
| **ادمین** | مدیریت همه کاربران + تغییر روت پیش‌فرض (main) |
| **سوپرادمین** | نام‌گذاری اینترفیس/جدول، ساخت جدول (v7)، نگاشت جدول↔اینترفیس |

## معماری فنی
```
internal/
  config/     تنظیمات و متغیرهای محیطی
  models/     مدل‌ها و ذخیره settings.json + بکاپ
  mikrotik/   ارتباط با API روتر (mangle، route، table، interface)
  handlers/   صفحات وب و کنترل دسترسی
```

## نحوه کار با MikroTik
1. برنامه از طریق **API باینری** (پورت پیش‌فرض ۸۷۲۸) به روتر وصل می‌شود.
2. برای هر کاربر قانون `mangle` با `mark-routing` ساخته می‌شود.
3. ترافیک آن IP به جدول روت مشخص‌شده هدایت می‌شود.
4. در RouterOS 7 جدول‌ها باید با فلگ `fib` وجود داشته باشند (برنامه در صورت نیاز می‌سازد).
5. در RouterOS 6 از پارامتر `routing-mark` استفاده می‌شود.

## محدودیت‌ها و نکات حرفه‌ای
- API باید روی روتر فعال باشد (`/ip service enable api`).
- کاربر API باید دسترسی کافی به firewall mangle، route و interface داشته باشد.
- برای کانتینر روی خود روتر، فقط دستگاه‌های با پشتیبانی Container (ROS 7.4+ و معماری مناسب) قابل استفاده هستند.
- توصیه می‌شود پنل روی یک دستگاه جدا (یا همان روتر با mount خارجی) اجرا شود و فقط از API استفاده کند.

## مشاهده لاگ
ادمین و سوپرادمین از مسیر `/logs` می‌توانند آخرین خطوط لاگ سیستم میکروتیک را **فقط مشاهده** کنند (بدون پاک‌کردن یا تغییر).

## رابط دوزبانه
پنل از منوی **FA | EN** زبان را عوض می‌کند. ترجمه‌ها در `internal/i18n/strings.go` هستند.
